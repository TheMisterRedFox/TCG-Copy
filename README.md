## Getting Started

### Installation

Build TCG-Copy from the source and install dependencies:

1. **Clone the repository:**

   ```sh
   git clone https://github.com/TheMisterRedFox/TCG-Copy
   ```

2. **Navigate to the project directory:**

   ```sh
   cd TCG-Copy
   ```

3. **Install the dependencies:**

    Using npm:

    ```sh
    npm install
    ```

### Usage

Run the project with:

**Using npm:**

```sh
npm run dev
```
